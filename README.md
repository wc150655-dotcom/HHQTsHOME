# 恨海情天 纯LE · 陪玩团官网

解构主义 + 极简杂志静奢风的陪玩团全站动态官网：**老板端**（前台）+ **超级管理员后台**（/admin），前端 100% 零硬编码，全部内容由后台数据库驱动。

## 快速开始

```bash
npm install      # 首次
npm run dev      # 开发服务器 → http://localhost:5173
npm run build    # 类型检查 + 生产构建（输出 dist/）
npm run preview  # 预览生产构建
```

## 双端口

| 端口 | 地址 | 说明 |
| --- | --- | --- |
| 老板端（前台） | `/` | 开场页 → 点击「恨海情天」标题进入主页 |
| 超级管理员后台 | `/admin` | 初始账号 **admin / admin123**（登录后请立即改密） |

前台导航栏与页脚均有「后台」入口；后台顶栏有「查看前台」。

## 功能总览

### 老板端
- **开场页**：标题「恨海情天」逐字渐变浮现（可替换为自定义标题图）；左下角逐字生成 + 随机模糊消隐文案（每次进入随机一条，全部参数后台可调）；鼠标 / 陀螺仪动捕晃动。
- **圆点光标**：进入网站后光标变为圆点，悬停交互元素放大（后台可关）。
- **左侧半圆钟表**：贴在页面最左侧、右半裁切；罗马数字刻度 + 轨道虚线 + 星点辅助线；指针跟随**现实北京时间**实时走动；音乐播放时表盘装饰缓慢旋转（暂停则装饰停止，指针永不停止）；点击钟表切换音乐、双击随机切歌；表盘正中心藏有半裁唱片（PC/平板显示，手机端为保持整洁自动隐藏）。
- **背景音乐**：进入页面首次点击自动播放；右上角唱片按钮旋转动画；后台可上传歌单、随机播放、音量、与钟表联动；无曲目时自动播放内置程序合成环境音。
- **主页**：顶部导航（角色切换 / 日夜间切换 / 唱片）· 陪玩团概况（编辑式排版：团名 Logo、简介、人数、服务游戏、营业时间 06:00–03:00、管理层与六大直属接待联系方式一键复制、应聘/下单入口）· 卡项分区（冠卡/包陪卡/VIP 三组切换，玻璃卡片悬浮发光）· 陪玩展示（音色/游戏/服务类型多条件组合筛选 + 详情页）· 本月头牌（第一名突出高亮）· 老板消费前三（塔罗牌翻面：日/月/星牌背 → 大阿尔卡纳 + 三张附属小牌展开释义，敏感数据匿名/打码）· 页脚（感谢名单档案袋、打赏二维码 + 50% 捐赠承诺 + 公开台账）。
- **适配**：PC + 手机双端；日间/夜间双主题；黑白灰单色 + 可配置强调色。

### 超级管理员后台（全站可视化）
- **站点设置**：标题/简介/Logo/主视觉/Favicon/营业时间/主题模式/强调色；6 项动效独立开关；音乐系统（歌单上传、自动/随机播放、音量、钟表联动）；敏感信息全局打码。
- **开场页**：标题图上传；左下角文案库无限条 CRUD + 全参数（字号/颜色/字距/行距/四边页边距/逐字速度/模糊与消隐范围）+ 动画预览。
- **选项库**：音色/游戏/服务类型（增删改名排序隐藏）+ 默认三头像，全站同步。
- **团队概况**：人数、服务游戏、管理层、六大接待、入口链接。
- **卡项管理**：冠卡/包陪卡/VIP 三组完整 CRUD + 上下架。
- **陪玩管理**：完整资料（头像三图随机/自定义、音色、游戏、服务、简介、签名、段位、价格、拓展字段开关、社交账号、战绩评价），退团自动前端隐藏。
- **头牌管理**：排名、业绩、徽章、光效、月度一键重置、从陪玩资料一键导入。
- **塔罗榜单**：日/月/星三席位固定；昵称匿名开关、金额打码开关（敏感区，操作永久留痕）；主牌 + 三张附属小牌图文释义；未配置时前端优雅空占位。
- **页脚台账**：感谢名单、打赏二维码、捐款记录台账（收入/捐款/时间/凭证）。
- **素材库**：全站图片上传/预览/改名/删除/复制链接。
- **账号权限**：超级管理员 + 子管理员模块级权限、冻结、改密、删除。
- **操作日志**：全部修改留痕（操作人/时间/模块/明细），敏感日志禁删。

## 数据说明

- 数据存储于浏览器 localStorage（键 `hhqt_db_v3`），**同设备内前后台实时同步**。
- 后台「总览 → 数据管理」支持**导出 / 导入 JSON 备份**，用于多设备同步或迁移；也可一键恢复默认数据（保留账号与日志）。
- 卡项价格、陪玩资料、头牌业绩等均为**示例占位数据**，请按团内真实情况在后台修改（包天/包夜等细则以腾讯文档为准）。
- 塔罗榜单默认未配置（按需求呈现「静候揭晓」空占位）。
- 图片/音频上传以 data URL 存储，受浏览器容量限制（约 5MB），大文件建议使用外链（粘贴链接）或后续接入服务端。
